# Security policy

Please report suspected vulnerabilities through [private GitHub Security Advisories](https://github.com/FORIFOR/php-safe-migrate/security/advisories/new). Do not include production credentials or sensitive project data in reports.

The tool performs static assessment only. Its bundled advisory catalog is incomplete, and a report must not be used as approval to deploy. Do not run future validation features against untrusted projects without container isolation and disposable data. Production changes require separate explicit approval.
